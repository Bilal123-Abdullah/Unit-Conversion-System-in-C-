 Unit Conversion System

A beginner-friendly C-based Unit Conversion System developed as a Programming Fundamentals project. The program allows users to convert values between different units of **Mass, Length, Time, Temperature, Speed and Volume.

Features

* Mass conversions:

  * Kilograms ↔ Grams
  * Kilograms ↔ Pounds
  * Grams ↔ Pounds
* Length conversions:

  * Centimeters ↔ Feet
  * Centimeters ↔ Inches
  * Centimeters ↔ Kilometers
* Time conversions:

  * Seconds ↔ Minutes
  * Seconds ↔ Hours
  * Hours ↔ Minutes
  * Days ↔ Hours
* Temperature conversions:

  * Fahrenheit ↔ Celsius
  * Fahrenheit ↔ Kelvin
  * Celsius ↔ Kelvin
* Speed conversions:

  * m/s ↔ km/h
* Volume conversions:

  * Liters ↔ Milliliters
  * Liters ↔ Gallons
* Stores conversion records in a text file using file handling.
* Menu-driven interface for easy navigation.

The main purpose of this project is to apply Programming Fundamentals concepts to develop a practical menu-driven application while learning how different C programming features work together in a complete project.
